브라우저 계산과 서버 저장

사용자의 기기에서 자바스크립트로 계산하는 서비스는 입력값을 서버로 보낼 필요가 없습니다. 이 사이트의 만세력·사주 도구는 현재 생년월일과 생시를 자체 데이터베이스에 저장하지 않습니다.

광고와 로그

GitHub Pages 같은 호스팅 사업자는 서비스 제공 과정에서 접속 로그를 처리할 수 있고, AdSense가 활성화되면 Google과 파트너가 광고 제공을 위해 쿠키나 기기 정보를 처리할 수 있습니다.

정책 확인 습관
