개인정보처리방침

생년월일·생시 입력, GitHub Pages 호스팅, Google AdSense와 관련한 개인정보 처리 원칙을 안내합니다.

시행일: 2026년 9월 1일

1. 사주 도구 입력정보

개인 사주 도구에서 입력하는 양력 생년월일과 출생 시각은 현재 사용자의 브라우저에서 자바스크립트로 계산됩니다. 운영자가 별도의 회원 데이터베이스에 해당 값을 저장하거나 전송하지 않습니다.

2. 회원정보

현재 회원가입 기능이 없으며 이름, 전화번호, 주민등록번호, 상세 주소를 사주 계산을 위해 요구하지 않습니다.

3. GitHub Pages

사이트는 GitHub Pages로 제공됩니다. 호스팅 사업자는 서비스 제공·보안·장애 대응을 위해 IP 주소, 접속 시각, 브라우저 정보 등 일반적인 서버 로그를 처리할 수 있으며 GitHub의 개인정보 관련 정책이 적용될 수 있습니다.

4. Google AdSense

사이트에는 Google AdSense 사이트 확인을 위한 게시자 계정 정보와 ads.txt가 포함되어 있습니다. 광고가 활성화되면 Google 및 광고 파트너가 광고 제공, 부정 이용 방지, 빈도 제한, 측정 등을 위해 쿠키, IP 주소, 기기 정보, 브라우저 정보, 광고 식별자 등을 처리할 수 있습니다.

5. 쿠키와 동의

사주·번호 생성 기능 자체는 이용자 추적용 쿠키가 필요하지 않습니다. AdSense 또는 분석 도구가 활성화되면 제3자 쿠키 등이 사용될 수 있습니다. 관련 법령에 따라 동의가 필요한 지역에서는 Google이 요구하는 동의 관리 플랫폼 또는 Privacy & messaging 기능을 사용할 수 있습니다.

6. 보유와 삭제

현재 자체 서버에 생년월일·생시를 저장하지 않으므로 해당 입력값의 보유 기간은 없습니다. 향후 문의 폼, 회원 기능, 분석 기능이 추가되면 수집 목적·보유 기간·삭제 방식을 본 방침에 반영합니다.

7. 외부 링크

외부 공식 자료로 연결될 수 있으며 외부 사이트의 개인정보 처리에는 해당 사이트의 정책이 적용됩니다.

8. 정책 변경과 문의

기능 또는 광고 방식이 변경되면 시행일과 내용을 갱신합니다. 문의는 문의 페이지를 이용해 주세요.
