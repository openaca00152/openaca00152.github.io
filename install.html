스마트폰 바탕화면에 설치하기

앱스토어를 거치지 않고 웹사이트를 홈 화면에 추가해 일반 앱처럼 실행할 수 있습니다.

Android · Chrome

  1. Chrome에서 openaca00152.github.io를 엽니다.
  2. 사이트 위쪽의 📱 설치 버튼을 누릅니다.
  3. 설치 창이 뜨면 설치를 선택합니다.
  4. 설치창이 뜨지 않으면 Chrome 메뉴(⋮)에서 앱 설치 또는 홈 화면에 추가를 선택합니다.

iPhone · Safari

  1. 반드시 Safari에서 사이트를 엽니다.
  2. Safari의 공유 버튼을 누릅니다.
  3. 홈 화면에 추가를 선택합니다.
  4. 오른쪽 위의 추가를 누릅니다.

스마트폰으로 바로 열기

PC 화면에서 이 QR 코드를 스마트폰 카메라로 스캔하세요.

설치하면 무엇이 달라지나요?

홈 화면에 福 아이콘이 생기고 주소창 없이 독립된 앱 화면처럼 실행됩니다. 만세력과 번호 생성 기능은 같은 웹사이트를 사용하므로 새 버전이 배포되면 별도의 앱 업데이트를 받을 필요 없이 최신 내용으로 갱신됩니다.

개인정보는 따로 저장되나요?

설치 여부와 관계없이 사주 계산 입력값은 현재 브라우저에서 계산하며 운영자의 별도 회원 데이터베이스에 저장하지 않습니다. 자세한 내용은 개인정보처리방침에서 확인할 수 있습니다.

설치 버튼이 보이지 않을 때
이미 설치되어 있거나 브라우저가 설치 조건을 아직 충족하지 않은 경우일 수 있습니다. Android에서는 Chrome 메뉴의 ‘앱 설치/홈 화면에 추가’, iPhone에서는 Safari의 ‘홈 화면에 추가’를 사용하세요.
